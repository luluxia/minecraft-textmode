# 物品、配方与成就改版设计

本案补充[系统改版讨论稿](./overworld-exploration.md)和[群系、结构与生物扩充设计](./world-content.md)。新增内容需要逐项确定物品用途、获取阶段和配方书提示。成就负责展示探索和经营成果，也能给玩家提供下一步可选目标。

## 物品如何进入游戏

现有物品分为材料、食物、奇物、工具和装备。保留这五类用于浏览。在设计新增条目时，先确定它是通用物资、提供新能力的专用物品，还是可选收藏。

| 用途 | 代表物品 | 来源与消费 |
| --- | --- | --- |
| 生存和建造 | 原木、木板、圆石、口粮、煤炭与木炭 | 让不同地点提供可互换的来源。工作台、箱子和普通村庄建筑优先消耗通用材料。食物保留各自的获取方式与饱食收益。 |
| 探索与制作工具 | 地图、刷子、望远镜、水肺药水 | 每件物品对应清楚的行动。地图记录地点，刷子开启考古，望远镜补充远行线索，水肺药水延长水下作业时间。配方书能跳到对应制作入口。 |
| 结构专属物品 | 藏宝图、试炼钥匙、嗅探兽蛋、海洋之心、鞘翅 | 保留原结构特色，由后续行动消耗或使用。首次奖励按地点或探索目标登记，个人探索和村庄远征共用记录。 |
| 地区特色及收藏 | 陶片、树脂、朱砂、木材和颜色变种 | 陶片可用于制作有对应纹样的陶罐。村庄建成市场后，4 个树脂团或 6 份朱砂可换 1 颗绿宝石。稀有地点掉落可以换来新选择，基础工具与定居所需材料保持可从常见地点获得。 |

### 通用配方与背包

- 橡木、白桦、云杉、杨木等原木保留各自名称和图鉴记录。普通木板、木棍和基础建筑可接受合适的木材，通用配方在配方书只显示一条。需要指定外观的制作再选择树种。
- 营火和火把各使用一条配方，材料栏标明「煤炭或木炭」。合成时从可用库存自动取材，批量制作可分别消耗两种材料。
- 背包、箱子和仓库按具体物品计算堆叠上限，各树种的原木和木板分别计数。用共用材料制作时先用本地库存，只有指定变种的配方才要求选择。
- 记录普通地点的地图、提供远行线索的探险家地图和定位埋藏宝藏的藏宝图各自标明用途。探险家地图的线索写入当前地点介绍，由远行自动参考。试炼钥匙和藏宝图是否消耗由对应行动明确显示。
- 关键配方早于首次获得成品可查。查看材料时显示已知来源与当前地点可用数量。只有一个随机来源的稀有物品适合支撑可选玩法。主线关键物品可以保留特定结构来源，此时应有可查询的寻找方法。
- 物品上线前核对获取方式、实际用途、堆叠归属、丢失后的补取渠道，以及旧物品能否承担同一用途。只有外观差异时，优先添加到现有物品组和配方。

## 成就如何对应新玩法

现有成就分为生存与维度、村庄与末地、遗迹与远航，部分提示还指向定向路线，部分判定只看持有物品或启用设施。建议沿用分类浏览和「当前目标」追踪，把常规引导改成已到阶段的多个可选目标。实际功能按生存准备、设施、地点和材料开放，成就完成记录对应行为。

| 分支 | 首轮候选目标 | 判定依据 |
| --- | --- | --- |
| 独立生存 | 第一次做饭；安家 | 在营火或熔炉完成一次食物加工；建成可用庇护所或在现成村庄正式定居。两项可独立完成。 |
| 附近探索 | 发现附近的隐藏内容 | 完成一次附近探索并揭示资源点、行动或线索。地点类型由实际存档决定。 |
| 远行和回访 | 循线启程；重返旧地 | 通过附近发现或探险家地图获得线索，选择对应的远行行动出发，抵达普通地点也可计入；离开后回到自己用地图记录的地点。 |
| 地点储存 | 就地取材 | 使用箱子或仓库里的材料完成当地制作或建设。 |
| 村庄起步 | 在村里安顿；第一位住民 | 主动选择在村中定居，或接纳首位住民。两条分支各自记录，都能继续进入共用的岗位成就。 |
| 村庄经营 | 第一班岗；自动化时代 | 首次获得自己管理的岗位产出；首次从运转中的红石产线获得产物。 |
| 遗迹与远航 | 古陶复原；海洋之心；珍藏密敛 | 用发现的陶片制作陶罐、依据藏宝图找到海洋之心，或开启试炼宝库。玩家亲自探索和有效远征都可完成适用目标。 |
| 维度和长期挑战 | 勇往直下；解放末地；方块纪元 | 使用传送门进入下界、击败末影龙、建成纪念碑。沿用主线和长期建设的实际条件。 |

### 目标提示与兼容

- 早期同时给出少量与当前进度相关的可选目标，例如备粮、附近探索、制作石镐。成就提示可以打开配方书，或定位到玩家已经知道的地点和线索。罕见结构的具体名称、掉落和位置随玩家的发现阶段逐步显示。
- 稀有路线和收藏成就独立于主线和经营。陶片可复原为陶罐并用于建造陶艺展馆。群系变种记录旅行经历。观察野生动物后，玩家在该物种的栖息地探索附近少耗 0.5 饱食，同一地点的多条观察记录共享这一次减免。奖励物资来自探索、战斗或生产。
- 采用实际完成事件和已有永久状态记录进度。离开未记录地点、使用掉材料、搬迁或暂停产线之后，已经完成的成就仍保留。前置关系用于表达真实依赖，两条入驻路线可分别完成各自目标，且不会挡住共同经营目标。
- 旧存档按已有证据保留历史成就，例如已定居、已开启宝库或已击败末影龙。若新条件需要旧存档从未记录的行为，例如实际收取产线产物，保留旧阶段记录，新目标在行为发生时完成。物品迁移与地点库存迁移一起设计，保留原数量和已发现记录；超出新堆叠上限的旧存货仍可取用。

首轮先更新通用木材、口粮、地图与箱子的使用规则，并同步调整开局、探索记录、定居和第一条产线相关成就。新增群系或结构落地时，再补对应物品的来源、用途与可选成就。

## 生物互动的用途

| 互动 | 玩家获得的选择 |
| --- | --- |
| 驯服或取得信任 | 每种伙伴结伴后持续提供适用的能力。狼协助陆战、豹猫预警、马节省当地行动饱食、驴缩短移动冷却、骆驼节省干旱地带的远行口粮，美西螈协助水下战斗，鹦鹉螺延缓耗氧。前往另一处栖息地遇到同类时，可以跟随探路，发现一处附近地点。当地已探尽时获得 2 点经验，每种动物在同一地点仅互动一次。 |
| 观察野生动物 | 海龟、青蛙、熊猫、鹦鹉、狐狸、山羊和北极熊提供栖息地经验。配方书的「发现」页列出已掌握的地形，可以据此规划探索路线。 |
| 就地互动 | 海豚提供沉船线索，哞菇供餐，犰狳提供制作狼铠的鳞甲，硫磺立方体帮助开采朱砂。收益直接在探索或生产时兑现。 |
