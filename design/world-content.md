# 群系、结构与生物扩充设计

本案为[生存、探索与制作系统改版讨论稿](./overworld-exploration.md)的内容补充。以 Minecraft Java 版为参考，纳入 Wilderness Bound 和 Chaos Cubed 中适合文字玩法的内容。原版的群系分布、结构与代表生物用来决定玩家会在哪里遇见什么。下面的行动、收益和解锁方式是本作的设计提案。[官方群系资料](https://help.minecraft.net/hc/en-us/articles/360046470431-Minecraft-Types-of-Biomes) · [官方结构资料](https://help.minecraft.net/hc/en-us/articles/360059615491-Rare-Structures-in-Minecraft) · [官方更新历程](https://www.minecraft.net/zh-hans/updates/minecraft-updates-timeline-and-evolution)

## 内容怎样进入地点制

- **群系决定基本的采集和可能的发现。** 玩家从地点描述就能知道这里适合补粮、采木、找矿还是下水。主要行动相同的原版变种可以共用地点模板，例如积雪平原和冰刺之地共用寒地资源，冰刺之地另有景观和稀有发现。配方书仍可分别收录玩家见过的变种。
- **小结构在当前地点内发现和处理。** 废弃营地、沉船、紫水晶晶洞和考古点通过「探索附近」出现。发现后在采集页开启对应行动，状态随地点保存。紫水晶晶洞属于地下自然特征，可以沿用相同的发现规则。
- **大结构作为可回访的目的地。** 探索当地迹象可以发现新的行动和远行线索。探险家地图也能提供线索。试炼密室、远古城市、林地府邸等在抵达后使用少量专属行动。沿线索遇到新地区仍能补给、采集或得到后续线索，抵达次数随存档和选择变化。
- **个人探索和村庄远征共用发现记录。** 玩家可以亲自下水、刷扫、潜行或挑战。驻地具备相应条件后，可对已发现的地点派队获取常规产物。一次性宝箱和首次奖励按同一个探索目标记录。派队所得进入村庄仓库。
- **内容服务于实际需求。** 新群系至少提供一个可感知的差异，例如更可靠的补给、一项新行动、一个有用的生物互动或通向目标的线索。木材和颜色变种可共用基础配方。装饰、收集和挑战内容留作玩家自选目标。

现版已有多数常见陆地地点，也有红树林、紫水晶洞、沙漠遗迹、试炼密室、远古城市等由定向路线进入的内容。海洋和末地则已有潜水或远征。首批扩充先给这些内容接上附近探索、随机远行与线索，再填补有明显玩法差异的群系。

## 主世界群系

| 群系或地点组 | 到了这里能做什么 | 代表发现 |
| --- | --- | --- |
| 平原、向日葵平原、草甸 | 采集种子和口粮，寻找可定居地点。草甸也可作为山地周边的补给地。 | 牛羊、马、村庄、废弃营地 |
| 森林、白桦森林、繁花森林、樱花树林 | 共用早期木材和基础觅食，繁花森林和樱花树林偏向蜂巢、花卉与养蜂。 | 蜜蜂、狼、花卉、废弃营地 |
| 针叶林、原始针叶林、斑驳森林 | 采集浆果、蘑菇和冷区木材。斑驳森林可通过倒木、杨树和层孔菌辨认。 | 狐狸、狼、古迹废墟、废弃营地 |
| 黑森林、苍白之园 | 黑森林有深色橡木、蘑菇和府邸线索。苍白之园的夜间探索可出现嘎枝，冒险收益以树脂和收藏物为主。 | 林地府邸、嘎枝、嘎枝之心 |
| 丛林、稀疏丛林、竹林 | 采竹子、可可、西瓜，搜寻庙宇。竹子和西瓜在遇到丛林时给玩家新增材料和补给选项。 | 熊猫、鹦鹉、豹猫、丛林神庙 |
| 沼泽、红树林沼泽 | 收集黏土、蘑菇和水边资源。沼泽夜间可以搜寻史莱姆，红树林提供泥巴与红树木材。 | 青蛙、史莱姆、女巫小屋 |
| 热带草原、沙漠、恶地 | 热带草原适合获取木材和接触村庄；沙漠偏向考古与遗迹；恶地可作为寻找金矿、陶瓦和矿井的去处。 | 犰狳、骆驼、尸壳、沙漠神殿、废弃矿井 |
| 积雪平原、积雪针叶林、冰刺之地 | 木材和口粮分布不同，兔子和冰屋可以成为补给发现。冰刺可提供辨识度和稀有冰材。 | 兔子、北极熊、流浪者、雪屋 |
| 风袭丘陵、山坡、山峰 | 丘陵和浅洞提供采石和采铁机会。山峰偏向山羊、积雪和洞穴线索，深处再导向更危险的目的地。 | 山羊、矿口、深暗之域线索 |
| 河流、沙滩、暖水海洋、寒冷海洋、深海 | 河岸和海滩用于钓鱼、收集甘蔗或寻找船只；浅海潜水找废墟，深海需要更好的水下准备。海温区分珊瑚、鱼类、冰与遗迹变体。 | 海龟、海豚、鹦鹉螺、沉船、海底废墟、海底神殿 |
| 蘑菇岛 | 罕见而相对安静的补给地点，适合采蘑菇、从哞菇获得食物或作为海上补给点。 | 哞菇、菌丝 |
| 浅层洞穴、溶洞、繁茂洞穴、深暗之域、硫磺洞穴 | 浅洞可用于升级工具；溶洞强调铜与滴水石；繁茂洞穴提供发光浆果与苔藓；深暗之域使用潜行；硫磺洞穴可随地表硫磺泉线索发现，提供硫磺、朱砂和饲喂硫磺立方体的互动。 | 紫水晶晶洞、美西螈、洞穴蜘蛛、发光鱿鱼、监守者、硫磺立方体 |

斑驳森林和废弃营地尤其适合补充从开局到制图之间的探索。硫磺洞穴则可以作为有明确地表迹象的可选深洞内容。[Wilderness Bound 发布说明](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3) · [Chaos Cubed 发布说明](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-2) · [苍白之园发布说明](https://feedback.minecraft.net/hc/en-us/articles/32385811139085-Minecraft-Java-Edition-1-21-4-The-Garden-Awakens)

## 主世界结构与探索目标

| 结构或目标 | 在哪里得到线索 | 主要行动与收益 |
| --- | --- | --- |
| 村庄、废弃营地 | 平原车辙、炊烟、林中的草床或储物箱 | 村庄负责交易、生产和定居。废弃营地可作为修整、少量补给或找到探险家地图的机会。 |
| 废弃矿井、刷怪笼房间、紫水晶晶洞 | 洞内木梁、铁轨、异常刷怪声或方解石 | 搜矿车、处理洞穴蜘蛛或其他刷怪威胁、寻找可回访的紫水晶点。沿用采矿与战斗行动。 |
| 雪屋、女巫小屋 | 雪地足迹或沼泽中的灯光 | 雪屋可提供初期补给，少量雪屋可发现地下室并触发救治事件。女巫小屋可调查或挑战，获得酿造线索或材料。 |
| 古迹废墟、沙漠水井、沙漠神殿、丛林神庙 | 林下露出的陶瓦、沙地人工砌石、藤蔓后的石墙 | 古迹废墟和沙漠水井偏向刷扫考古。沙漠神殿与丛林神庙偏向识别陷阱后搜寻宝箱。 |
| 掠夺者前哨站、林地府邸 | 旗帜、村民消息、黑森林地图 | 前哨站可侦察、救援或挑战队长。府邸提供更高风险的救援与战斗，并给予不死图腾等可选奖励。袭击仍由已有村庄玩法承接。 |
| 沉船、埋藏宝藏、海底废墟、海底神殿 | 海岸漂流物、藏宝图、浅滩石墙或深海迹象 | 沉船搜图，埋藏宝藏取得海洋之心；废墟可刷陶片，暖水废墟可找嗅探兽蛋；海底神殿需要水下补给并应对守卫者，产出海晶材料和海绵。 |
| 试炼密室、远古城市 | 铜和凝灰岩构造、洞穴探险家地图或幽匿迹象 | 试炼使用现有的分批战斗、钥匙和宝库。古城可以铺羊毛潜行取物，也可以选择挑战监守者。 |
| 废弃传送门、要塞 | 露在地表的传送门残骸；末影之眼指引要塞 | 废弃传送门提供黑曜石等补给及传送门线索。要塞可含图书馆、蠹虫和传送门房间，沿用末影之眼这一专门的主线定位机制。 |

现有小型沙漠考古点可以归为水井周边的可疑沙层；沙漠神殿单独提供陷阱和宝箱。现有海滩的守卫者挑战则可以转到深海神殿。这样副本身份更清楚，原有刷扫、水肺和战斗行动仍能复用。[原版结构与战利品分布](https://help.minecraft.net/hc/en-us/articles/360059615491-Rare-Structures-in-Minecraft) · [海底神殿](https://www.minecraft.net/en-us/article/ocean-monument)

## 生物怎样改变行动

| 互动 | 优先内容 | 文字玩法 |
| --- | --- | --- |
| 维持口粮与原料 | 猪、牛、羊、鸡、兔、鱼类、蜜蜂、哞菇 | 沿用狩猎、钓鱼、剪羊毛和取蜜。群系改变可用食物；找到适合的动物后可以把对应产出引入村庄。 |
| 驯养和陪伴 | 狼、猫、马、驴、骆驼、鹦鹉、犰狳 | 狼可协助少量野外战斗，犰狳鳞甲用于狼铠；马、驴和骆驼可共用一套陆路载具规则。猫、鹦鹉可先作为村庄或随行互动。首轮挑有明确作用的生物落地。 |
| 水域与考古 | 海龟、海豚、美西螈、鹦鹉螺、嗅探兽 | 海龟关联水下补给，海豚可作为沉船迹象，美西螈可协助水下遭遇。鹦鹉螺可作为中期水下探索的准备选项，与现有鹦鹉螺壳物品分别显示。沿用嗅探兽孵化及寻找古代种子的玩法。 |
| 普通敌对遭遇 | 苦力怕、僵尸、骷髅、蜘蛛、史莱姆及其区域变体 | 苦力怕先给嘶声提示，让玩家选择撤退、防御或抢攻。尸壳、溺尸、流浪者等沿用战斗框架，由环境和招牌行为体现差异。 |
| 地点专属威胁 | 掠夺者、唤魔者、远古守卫者、旋风人、沼骸、监守者、嘎枝 | 每组先实现一项可读的规则，例如缺氧下的战斗、风弹、声响积累，或寻找嘎枝之心。玩家在投入战斗前可从描述看到准备方向。 |
| 和平交互与村庄经营 | 村民、流浪商人、悦灵、铁傀儡、铜傀儡 | 流浪商人适合作为罕见种子和探索消息的来源；悦灵可协助收集一个指定物品；铜傀儡可作为箱子和仓库的可选整理功能。铁傀儡继续负责防御。 |

生物变种可以随群系和季节出现，界面在它会改变行动时提示。鳞甲、随行动物、海洋坐骑和仓库整理可分别放在已有的装备、远行、潜水和储存入口。[犰狳与狼铠](https://www.minecraft.net/en-us/article/armored-paws) · [悦灵](https://www.minecraft.net/zh-hans/article/meet-allay) · [铜傀儡](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21-9) · [鹦鹉螺](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21-11)

## 下界和末地的内容储备

| 区域 | 代表群系、结构与生物 | 可对应的现有玩法 |
| --- | --- | --- |
| 下界 | 下界荒地、诡异森林、绯红森林、灵魂沙峡谷、玄武岩三角洲；下界要塞、堡垒遗迹；烈焰人、凋灵骷髅、猪灵、疣猪兽、炽足兽、恶魂、岩浆怪 | 五种群系分别偏向基础材料、末影珍珠、交易与食物、灵魂材料、火山岩与岩浆威胁。要塞提供烈焰棒，堡垒遗迹作为可选高风险战利品点。沿用现有传送门、猪灵交易、战斗和酿造。 |

下界和末地入口沿用主线方案，优先保留现有内容。外岛变种可先作为远征地点和奖励差异。[下界和末地群系](https://help.minecraft.net/hc/en-us/articles/360046470431-Minecraft-Types-of-Biomes) · [下界与末地结构](https://help.minecraft.net/hc/en-us/articles/360059615491-Rare-Structures-in-Minecraft)

## 内容落地顺序

1. **先连通前中期。** 用既有群系、村庄和浅洞支持独立生存，加入废弃营地、废弃矿井和苦力怕。把原来依赖定向路线的地点接入探索，优先覆盖能解开补给、矿物和制图需求的发现。
2. **再拓宽探索目标。** 增添热带草原、恶地、黑森林、洞穴变体和海温差异，优先复用考古、潜水、已有战斗和委托。每类新增地点至少带来一种值得回访的行动。主线材料同时保留多个可接触的来源。
3. **继续补全稀有内容。** 加入府邸、苍白之园、蘑菇岛、硫磺洞穴和较少见的生物互动，以及两个维度的剩余变种。完成收集和挑战的节奏由玩家决定。配方书随发现补全来源，未发现的罕见内容可以先留线索。

新增物资的用途、配方、容量和成就条件见[物品、配方与成就改版设计](./items-and-achievements.md)。
